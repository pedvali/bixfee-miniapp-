⚡ راهنمای سریع راه‌اندازی Backend API
==========================================

📌 وضعیت فعلی: مینی اپ در حالت نمایشی (Demo Mode) است

✅ برای خروج از Demo Mode و استفاده کامل:

==========================================
🚀 روش 1: اجرای محلی (برای تست سریع)
==========================================

1. Terminal را باز کنید
2. دستورات زیر را اجرا کنید:

   cd F:\Bixfee\my_telegram_bot\my_telegram_bot
   pip install Flask flask-cors
   python miniapp_api.py

3. در app.js خط 32 را تغییر دهید:
   
   به جای: return null;
   بنویسید: return 'http://localhost:5000/api';

4. مینی اپ را تست کنید ✅

==========================================
🌐 روش 2: Railway (رایگان - پیشنهادی)
==========================================

1. به https://railway.app بروید
2. New Project → Deploy from GitHub
3. Repository خود را انتخاب کنید
4. بعد از Deploy، URL دریافت کنید (مثلاً: https://bixfee-api.railway.app)
5. در app.js خط 32 را تغییر دهید:
   
   return 'https://bixfee-api.railway.app/api';

6. فایل app.js را به GitHub آپلود کنید
7. مینی اپ را تست کنید ✅

==========================================
🔧 تنظیمات app.js
==========================================

باز کنید: my_telegram_bot/my_telegram_bot/miniapp/app.js

خط 32 را پیدا کنید:
   
   return null; // null = استفاده از Demo Mode

به این تغییر دهید (URL خود را جایگزین کنید):
   
   return 'https://your-backend-api.com/api';

مثال‌ها:
- Railway: return 'https://bixfee-api.railway.app/api';
- Render: return 'https://bixfee-api.onrender.com/api';
- VPS: return 'https://api.yourdomain.com/api';

==========================================
✅ بعد از تنظیم
==========================================

1. فایل app.js را به GitHub آپلود کنید
2. مینی اپ را در تلگرام باز کنید
3. باید به Backend متصل شود ✅
4. دیگر Demo Mode نیست! 🎉
