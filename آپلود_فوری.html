🚨 راهنمای فوری - آپلود Mini App

⚠️ مشکل: صفحه https://pedvali.github.io/bixfee-miniapp-/ هنوز محتوای قدیمی را نشان می‌دهد.

📋 مراحل آپلود (گام به گام)

مرحله 1: حذف فایل‌های قدیمی

  1. به Repository بروید
  2. روی فایل index.html کلیک کنید
  3. روی آیکون 🗑️ Delete (سمت راست بالا) کلیک کنید
  4. پیام Commit: Delete old files
  5. Commit changes را بزنید

همین کار را برای: app.js و style.css (اگر وجود دارند) انجام دهید

مرحله 2: آپلود فایل‌های جدید

  1. در صفحه Repository، روی "Add file" → "Upload files" کلیک کنید
  2. این 3 فایل را از پوشه miniapp انتخاب کنید:
    /root/Pedram/Bixfee/my_telegram_bot/miniapp/index.html
    /root/Pedram/Bixfee/my_telegram_bot/miniapp/styles.css
    /root/Pedram/Bixfee/my_telegram_bot/miniapp/app.js
  3. ⚠️ مهم: فایل‌ها را مستقیماً در root آپلود کنید (نه در پوشه miniapp)
  4. پیام Commit: Update Mini App with Trust Wallet design
  5. Commit changes را بزنید

مرحله 3: بررسی تنظیمات GitHub Pages

  1. به Settings → Pages بروید
  2. مطمئن شوید:
    • Source: Branch = main
    • Folder: / (root) ⚠️ باید root باشد!
  3. Save کنید (اگر تغییر دادید)

مرحله 4: منتظر بمانید و تست کنید

  1. 5-10 دقیقه صبر کنید (GitHub Pages نیاز به rebuild دارد)
  2. Cache مرورگر را پاک کنید: Ctrl + Shift + R
  3. یا از حالت Incognito/Private تست کنید
  4. به صفحه بروید

🔍 بررسی اینکه فایل جدید است:

بعد از آپلود، به این آدرس بروید:

https://github.com/pedvali/bixfee-miniapp-/blob/main/index.html
  • ✅ اگر خط 22 را می‌بینید: <header class="app-header"> → فایل جدید است
  • ❌ اگر خط 12 را می‌بینید: <h1>به Bixfee خوش آمدید</h1> → فایل قدیمی است!

⚠️ اگر هنوز مشکل دارید:

  1. بررسی کنید که فایل‌ها واقعاً جدید هستند (خط 22 باید app-header باشد)
  2. Force rebuild: در Settings → Pages، Unpublish و دوباره Save کنید
  3. بررسی در حالت Incognito: اگر کار کرد → مشکل از cache است
